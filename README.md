# Google 表單快填工具 📝

快速生成 Google 表單自動填寫書籤，一鍵填入你的常用資料！

🔗 **線上使用**：https://joanna8799.github.io/form-filler/

## ✨ 功能

- 自動填入噗浪帳號、暱稱、匯款資訊、收件資料等
- 自動勾選電子郵件記錄
- 自動選擇寄送方式、匯款帳戶
- 自動填入當下時間（預計匯款時間）
- 自動勾選「確認已看過流程」

## 📖 使用方式

### 1. 生成你的專屬書籤

1. 前往 [工具頁面](https://joanna8799.github.io/form-filler/)
2. 填入你的個人資料
3. 點擊「生成我的專屬書籤」
4. 複製生成的程式碼

### 2. 建立書籤

1. 在 Chrome 按 `Ctrl+Shift+B` 顯示書籤列
2. 對書籤列按右鍵 →「新增頁面」
3. 名稱填：`團購快填`
4. 網址貼上剛才複製的程式碼

### 3. 使用書籤

1. 開團時打開 Google 表單
2. 等頁面載入完成
3. 點一下書籤列上的「團購快填」
4. 檢查資料，手動選擇購買數量
5. 按「提交」送出

## ⚠️ 注意事項

- 此工具僅適用於 Google 表單
- 每個表單的欄位可能略有不同，請填寫後再次確認
- 書籤內含你的個人資料，請勿分享給他人

## 🛠️ 技術說明

此工具使用 JavaScript Bookmarklet 技術，透過 DOM 操作自動填入表單欄位。
